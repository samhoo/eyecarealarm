# EyeCareAlarm 托盘设置面板 — 设计计划

## 意图摘要

为一个 Windows / macOS 桌面应用（护眼提醒工具 EyeCareAlarm）设计**状态栏 / 托盘图标点击后弹出的设置面板**原型。目标是做一个接近原生桌面体验的单屏弹窗原型：紧凑、浅色为主、交互控件齐全（开关 / 数字步进输入 / 滑动条 / 下拉框），信息层级清晰，一眼读完。

交付形态：单个 HTML 交互原型（桌面弹窗画布），非网页。

## 布局结构（来自用户示意，自上而下）

弹出面板整体宽度约 300px，内容分四段：

```
┌──────────────────────────────┐
│  x分x秒后眼睛休息一下            │  ← 顶部倒计时提示（动态）
│  提醒休息眼睛            [开关]  │
│ ──────────────────────────   │
│  立即提醒                       │  ← 动作行，点击立即触发一次休息提醒
│  提醒间隔        [ 25 ]分钟     │  ← 数字输入 + 上下步进
│  休息时长        [ 20 ]秒       │
│  遮罩透明度      42% <─o───>   │  ← 滑动条 + 百分比
│  音效           [水滴  ▾]      │  ← 下拉选择
│  音量           30% <───o─>   │
│  语言           [中文  ▾]      │
│  开机自启动               [开关] │
│ ──────────────────────────   │
│  更多护眼知识        →          │  ← 链接项
│  关于 EyeCareAlarm version 0.1.23 │  ← 页脚版本信息
│  退出 EyeCareAlarm              │  ← 退出项（危险操作）
└──────────────────────────────┘
```

## 组件清单与状态

| 组件 | 类型 | 交互规则 |
|---|---|---|
| 倒计时提示 | 文本（动态） | 显示"x分x秒后眼睛休息一下"，x 随提醒间隔实时变化，灰色 |
| 提醒休息眼睛 | 开关 | 顶部主开关；关闭时折叠面板，仅保留本开关行与「退出」，开关行绝对位置不变 |
| 立即提醒 | 动作行 | 点击立即触发一次休息提醒，倒计时重置为完整间隔；原型内以 toast 反馈 |
| 提醒间隔 | 数字输入 + 步进 | 范围建议 20–120 分钟，默认 20；输入框内可手输，箭头 ±1 |
| 休息时长 | 数字输入 + 步进 | 范围建议 5–60 秒，默认 20 |
| 遮罩透明度 | 滑动条 | 0–100%，默认 20%（与遮罩页缺省对齐）；左侧显示百分比并实时更新 |
| 音效 | 下拉框 | 选项：颂钵 / 提示音 / 无；默认颂钵 |
| 音量 | 滑动条 | 0–100%，默认 30%；左侧显示百分比 |
| 语言 | 下拉框 | 选项：简体中文 / English；默认简体中文 |
| 开机自启动 | 开关 | 默认开 |
| 更多护眼知识 | 链接行 | 悬停高亮，点击跳外部链接 |
| 关于 | 页脚文本 | 静态信息行 |
| 退出 EyeCareAlarm | 危险操作行 | 红色或警示色文本，悬停提示；点击即退出（原型内不做真实退出，显示交互反馈） |

## 视觉系统方向

- 风格：原生桌面弹窗质感 — 无页面骨架、无浏览器痕迹；面板悬浮、带圆角（约 12px）与柔和投影（elevation），边缘 1px 描边，接近 macOS 菜单 / Windows 托盘弹窗。
- 配色：浅色系统面板，中性色为主；单一强调色（如品牌绿或蓝）仅用于主开关与焦点态；退出项用警示红。避免渐变色与夸张装饰。
- 字体：中文系统字体栈（PingFang SC / Microsoft YaHei）+ 等宽字体用于数字/倒计时，显示清晰。
- 控件风格统一：开关、滑动条、步进按钮均为自定义绘制但贴近原生观感，hover/active 有明确状态反馈。
- 待定：是否做深色模式（macOS 深色）——见开放问题。

## 可访问性与操作细节

- 整面板所有触控/点击目标高度 ≥ 32px（桌面光标场景，不低于原生菜单行高）。
- 滑动条与步进输入支持键盘方向键调节（原型中实现）。
- 数字输入夹紧在 min/max 范围内。
- 下拉框点击展开选项列表，点击外部收起。
